    # 趋势交易分析规则

    ## Decision Pipeline Rule（决策流程约束）

    1. 模型必须首先基于结构、趋势、动量指标完成 decision_gate 判断（TRADE / NO_TRADE）。
    2. 在 decision_gate = NO_TRADE 的情况下：
      - 不得引用 ATR
      - 不得描述波动性、止损宽窄、风险空间
    3. 仅当 decision_gate = TRADE 时：
      - 允许计算 ATR
      - ATR 仅用于计算 STOP_LOSS_DISTANCE 与盈亏比
    4. ATR 不得作为任何判断是否允许交易的前置条件或隐含依据。

    ## 0. 时间框架角色规则（Timeframe Role Rule）

    ### Primary Timeframe
    - 由输入字段 `"timeframe"` 指定，例如 `"15m"`
    - **唯一拥有决策权**：
      - 趋势方向（UP / DOWN / SIDEWAYS）
      - 趋势阶段（IMPULSE / PULLBACK / CORRECTION / CONSOLIDATION）
      - 支撑 / 阻力
      - 止损、止盈
      - 盈亏比（estimated_risk_reward）
      - confidence
    - 所有决策型、判断型、结构型计算 **必须基于 Primary Timeframe**
    - **ATR 规则（重要）**：
      - ATR 的计算周期以 Primary Timeframe（15m）为主
      - 可参考 Secondary Timeframe（1h）ATR 作为波动尺度校准
      - 1h ATR **仅用于防止 15m ATR 过窄**
      - 不得替代、否定或覆盖 15m ATR
      - 不得改变 Primary Timeframe 的趋势判断与 decision_gate

    ### Secondary Timeframe
    - 默认比 Primary 高一级（如 Primary=15m → Secondary=1h）
    - **仅用于方向一致性检查（Directional Filter）**
    - 可以回答：是否存在明显方向冲突
    - **不得参与任何数值计算**
    - **不得影响 confidence、盈亏比或 decision_gate**

    ### Tertiary Timeframe
    - 默认比 Primary 高两级（如 Primary=15m → Tertiary=4h）
    - **仅用于极端风险否决（Risk Veto）**
    - 仅在出现明确、结构级别的强反向趋势时生效
    - **不得降低 confidence**
    - **不得参与交易构造或仓位计算**

    ### Lower Timeframes
    - 如 5m 数据，可用于短线动能或节奏观察
    - **不得改变 Primary 的止损 / 止盈 / 仓位计算**

    ## 1. 趋势分析与置信度

    - 计算趋势方向：UP / DOWN / SIDEWAYS
    - 判断趋势阶段：IMPULSE / PULLBACK / CORRECTION / CONSOLIDATION
    - 评估趋势风险：LOW / MID / HIGH
    - 计算 confidence（0~1）
      - confidence = 趋势强度
      - **仅基于技术指标与市场结构**
      - 不参考仓位、资金、盈亏、ATR

    ## 2. 交易信号与决策门

    - **预估盈亏比计算（estimated_risk_reward）**
      - 基于 Primary Timeframe 的结构空间
      - ATR 仅在 decision_gate = TRADE 后用于止损距离校准
      - 若 estimated_risk_reward < 3.5：
        - decision_gate = NO_TRADE
        - reason_code = ["RISK_REWARD_LOW"]
        - trading_signal.action = "HOLD"
        - trading_signal.position_size = 0
        - trading_signal.stop_loss = 0
        - trading_signal.take_profit = 0

    - 若 confidence < 0.7：
      - 不输出 BUY / SELL
      - trading_signal.action = "HOLD"
      - position_size / stop_loss / take_profit = 0
      - decision_gate = NO_TRADE
      - reason_code 可加 ["LOW_CONFIDENCE"]

    - 高置信度交易（confidence ≥ 0.7 且 盈亏比 ≥ 3.5）：
      - 输出 BUY / SELL
      - 附带止损、止盈、仓位
      - decision_gate = TRADE
      - reason_code = []

    ## 3. 仓位管理（仅对已有仓位生效）

    - 如果没有传入 current_position：
      - position_adjustment.action = HOLD

    - position_adjustment 允许动作：
      - ["HOLD", "CLOSE_LONG", "CLOSE_SHORT"]
      - ❌ 不允许 BUY / SELL
      - ❌ 不允许加仓 / 减仓
      - ❌ 不允许改杠杆

    - 允许 CLOSE 的条件：
      - 趋势反转（UP ↔ DOWN）
      - 关键结构破坏（EMA / VWAP / 支撑位）
      - 波动异常（ATR 急剧放大且方向不利）

    - position_adjustment 不得参考 confidence
      - confidence 仅用于新交易是否允许
      - 平仓判断仅基于价格 vs 结构 / 趋势反向

    ## 4. 严格约束

    - 一旦 decision_gate = NO_TRADE：
      - trading_signal.action = HOLD
      - position_size / stop_loss / take_profit = 0
    - current_position 仅用于 position_adjustment
    - trend_analyzer 与 confidence 不得读取 current_position
    - 高置信度交易才允许 BUY / SELL 并附带止损止盈和仓位

    - position_adjustment 只对已有仓位生效，无仓位忽略输出
    - 输出 JSON 必须逻辑一致，不允许矛盾
    - 只保留可解析字段数据
    - **不输出 enum、description、calculation_method 等元数据**
